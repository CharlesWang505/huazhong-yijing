# 计分与决策

规则以 2026-11-16 两个会话中的客户端实测为基准。本地规则文档和 HTML 是辅助资料；未来客户端显示有变化时重新校验。只记录可说明选择的判断依据，不逐字重放内部推演。

## 基础状态

普通关开局 8 张手牌、6 次出牌、6 次弃牌；单次最多选 6 张，也可少出。每次出牌或弃牌后补足手牌；抽牌堆耗尽后重洗弃牌堆。初始次数、奖励和目标仍须从当次界面确认。

## 基础增益

初始十项为基础点数、同名、四种同兵种、红橙蓝品质、三分天下。

| 条件 | 额外伤害 |
|---|---:|
| 每组至少三张同名 | 每组 +20 |
| 同兵种至少三张 | 每种 +10 |
| 红牌至少三张 | +30 |
| 橙牌至少三张 | +20 |
| 蓝牌至少三张 | +10 |
| 刘备、孙权、曹操各至少一张 | +80 |

同名、兵种、品质可以叠加。早期曾把蓝盾组合估低 20 分，就是漏算同名；不要只按红牌数量或单张点数选牌。

## 三处实测修正

### 点将成阵的门槛独立

第八关首手为“两刘备、两吕蒙、张飞、弓兵”。旧计算 223，游戏预览 183，恰好多算两组各 20。修正为同名组 `count >= 3` 才增加点将伤害；两张同名仍可触发双壁、橙色同名联动或族兵等各自符合的效果。

这手是脚本回归样例。发生不一致时应对照分项，修正后重新枚举，避免只把总分减去一个常数。

### 点名追击不是“连续两手”

中间未触发同名的手没有清除下一次同名的追击资格。本次旧 `lastSame` 参数被用作“本关此前是否触发过同名”；独立脚本改用 `pursuitArmed`，更新为 `previous || currentSameNameTriggered`，新关才重置。

弃牌不会构成一次出牌，也不会清除此状态。状态未知时不要默认真或假，可比较两个状态的预测与当前预览。

### 稀有共鸣的“品质相关”按实测收窄

旧 HTML 统计四红、橙气、低星、阶梯、族兵等扩展增益。最终关预览支持的口径是当前触发了几种基础品质增益：三红 +8，三橙 +8，三蓝 +8。实测覆盖单种 +8、红加橙 +16、红加蓝 +16。

六张上限下最多同时触发两种，所以本次可见上限为 +16。这是本次版本的观察模型，不能外推为未来版本或其他未知模式的永久规则。

## 出牌、弃牌与构筑的判断依据

普通关优先让剩余总伤害够用。设剩余血量 H、剩余出牌 P，`H/P` 可作紧迫程度的粗略参考，不能当作未来每手保证。当前组合能直接收尾时，通常直接结束比继续追分更有价值。

首手达到 `ceil(目标/4)` 可拿精算奖励：第四关 105、第五关 118、第六关 130、第七关 143、第八关 155。为了这点奖励换牌前，先判断保留核心和弃牌次数能否支撑本关；无尽关不据虚拟血量估算奖励。

弃牌独立于出牌。前期错误之一是弱手也直接出，把出牌次数用紧后才想起还有大量弃牌。保留能成组的牌，换掉对当前构筑贡献低的散牌；补牌后以新的完整手牌重新枚举。

保留什么随构筑变化：早期双壁提高重复牌价值；四红使三张红牌成为明确门槛；刘备、王者和蜀汉增强盾牌；族兵、蓝海、低星使蓝牌能有高收益；四兵齐备又让蓝弓等低点数牌成为关键组件。避免形成“永远弃蓝”或“永远追六红”的固定策略。

脚本求的是当前单手最优。剩余出牌很多时，可保留关键君主搭配下一手；最后一手则主要看当前得分。已知道完整抽牌池时才估算换牌概率，未掌握数量时用定性判断，不编造成功率。

本次通关墨卷为 `1 + 剩余出牌次数 + 已确认的额外奖励`，剩余弃牌不计奖。游戏商店实际价格低于本地 HTML 静态标价，必须读当前商品价格；买后商品会刷新，重新观察，再决定下一笔。根据实际剩余墨卷、核心联动和牌库选择新增或删牌；本次多次补刘备有效，不代表所有牌局都该只加刘备。

## 最后一手的完整校验

手牌为曹操、刘备、关羽、张飞、吕蒙、枪兵、枪兵、盾兵。持有本轮全部增益，`pursuitArmed=true`、`armyTriggered=true`。

选择第 1、2、3、6、7、8 张，输出 218：基础 21、枪兵同名及族兵 20、追击 15、三红 30、四红 20、三蓝 20、稀有共鸣 16、三盾 10、整军 12、王者 24、蜀汉 30。

这手在游戏预览和最终累计分两处得到验证：1049 + 218 = 1267。脚本 `--demo` 可复现；它不把未知洗牌伤害或未来抽牌加进 218。
